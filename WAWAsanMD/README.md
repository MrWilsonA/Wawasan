## 2. Filosofi & Metode Pengajaran

WAWAさん dibangun di atas lima prinsip. Setiap modul di platform ini wajib mematuhi kelimanya.

### Prinsip 1 — Bunyi Sebelum Bentuk (*Sound before Script*)

Otak tidak bisa menghafal simbol yang belum punya bunyi. Karena itu **setiap bahasa selalu dimulai dari sistem bunyi**, bukan dari kosakata.

```
BUNYI  →  AKSARA  →  KATA  →  POLA KALIMAT  →  WACANA
 (1)       (2)       (3)         (4)            (5)
```

Melompati tahap 1 adalah penyebab nomor satu kegagalan pelajar Indonesia di bahasa bernada (Mandarin) dan bahasa berbatchim (Korea).

### Prinsip 2 — Aksara Diajarkan Lewat Cerita, Bukan Hafalan Buta

Karakter 日 tidak dihafal sebagai "coretan kotak dengan garis". Ia diajarkan sebagai **gambar matahari** yang berevolusi selama 3.000 tahun:

```
☉  →  ⊙  →  ⊖  →  日
Matahari    Tulang     Perunggu   Bentuk
(±1200 SM)  ramal      (Zhou)     modern
```

Karakter yang punya cerita bertahan di memori 5–10× lebih lama daripada karakter yang dihafal mentah. Setiap aksara di WAWAさん punya bagian **"Dari Mana Asalnya?"**.
→ Lihat [`02-jepang-aksara.md`](02-jepang-aksara.md) dan [`04-mandarin-hanzi.md`](04-mandarin-hanzi.md).

### Prinsip 3 — Tangan Ikut Belajar (*Motor Encoding*)

Menulis dengan tangan mengaktifkan jalur motorik yang memperkuat ingatan visual. Setiap modul aksara punya **lembar latihan menulis** dengan:

- kotak 田字格 (Mandarin) / 十字格 (Jepang)
- urutan guratan bernomor
- target repetisi harian yang realistis (bukan "tulis 100×")

→ Lihat [`07-latihan-menulis.md`](07-latihan-menulis.md).

### Prinsip 4 — Satu Konsep Baru per Sesi (*Cognitive Load Management*)

Setiap unit hanya memperkenalkan **satu** struktur tata bahasa baru, ditemani kosakata yang sudah dikenal. Contoh salah vs benar:

| ❌ Cara yang membingungkan | ✅ Cara WAWAさん |
|---|---|
| "Pelajari partikel は、が、を、に、で sekaligus" | Unit 4: hanya は. Unit 5: hanya を (memakai kosakata Unit 4). Unit 6: が dikontraskan dengan は yang sudah dikuasai. |

### Prinsip 5 — Spaced Repetition Terjadwal

Kosakata diulang pada interval **1 – 3 – 7 – 16 – 35 – 90 hari**. Setiap unit menutup dengan daftar "Kartu Hari Ini" yang siap dimasukkan ke Anki/kertas.

## 4. Alur Belajar Wajib (Urutan Tidak Boleh Dilompati)

Setiap bahasa mengikuti **enam gerbang**. Gerbang berikutnya terkunci sampai gerbang sebelumnya lulus.

```
┌─────────────────────────────────────────────────────────────┐
│  GERBANG 0 — SISTEM BUNYI                                   │
│  Mendengar & menirukan sebelum melihat tulisan.             │
│  JP: 5 vokal, mora, aksen nada  │  CN: pinyin + 4 nada      │
│  KR: 10 vokal + 14 konsonan     │  EN: 44 fonem, stress     │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  GERBANG 1 — AKSARA                                         │
│  Sejarah → bentuk → urutan guratan → latihan tangan.        │
│  JP: hiragana → katakana → 80 kanji dasar                   │
│  CN: guratan → radikal → 300 hanzi dasar                    │
│  KR: jamo → suku kata → batchim                             │
│  EN: (dilewati — aksara Latin sudah dikuasai)               │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  GERBANG 2 — KATA INTI (±800 kata frekuensi tertinggi)      │
│  Benda → kerja → sifat → angka & waktu → keterangan         │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  GERBANG 3 — TULANG KALIMAT                                 │
│  JP: partikel + bentuk kata kerja (SOV)                     │
│  CN: urutan kata + partikel aspek 了/着/过 (SVO)             │
│  KR: partikel + tingkat tutur (SOV)                         │
│  EN: 12 tenses + klausa                                     │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  GERBANG 4 — PRODUKSI (bicara & tulis)                      │
│  Output terkontrol → output bebas → koreksi                 │
└───────────────────────────┬─────────────────────────────────┘
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  GERBANG 5 — STRATEGI UJIAN                                 │
│  Format soal, manajemen waktu, simulasi penuh berwaktu      │
└─────────────────────────────────────────────────────────────┘
```

**Aturan kelulusan gerbang:** minimal **85% akurasi** pada kuis penutup gerbang, diulang dua hari berturut-turut. Nilai 84% = ulang gerbang, tanpa pengecualian.

## 8. Sistem Penilaian Internal WAWAさん

Setiap unit ditutup dengan kuis. Rubrik yang dipakai di seluruh platform:

| Skor | Label | Tindakan Wajib |
|---|---|---|
| 95–100% | 完璧 Sempurna | Lanjut. Jadwalkan ulang materi ini di H+7. |
| 85–94% | 合格 Lulus | Lanjut. Tandai butir yang salah untuk ulangan H+3. |
| 70–84% | 要復習 Perlu Ulang | **Jangan lanjut.** Ulangi unit, kerjakan ulang kuis H+2. |
| < 70% | 不合格 Belum | Ulangi unit **dari awal**, termasuk latihan menulisnya. |

**Empat keterampilan dinilai terpisah.** Seseorang bisa 95% di Membaca tetapi 60% di Menyimak — dan yang menentukan kelulusan gerbang adalah **nilai terendah**, bukan rata-rata. Ini meniru logika ambang bagian JLPT dan mencegah "kepintaran timpang".

```
Nilai Gerbang = MIN(Menyimak, Membaca, Menulis, Berbicara)
```

## 9. Rutinitas Harian & Mingguan

### Template Sesi Harian (60 menit)

| Menit | Aktivitas | Tujuan |
|---|---|---|
| 0–10 | **Review SRS** — kartu jatuh tempo hari ini | Konsolidasi memori |
| 10–20 | **Latihan menulis** — 5 aksara baru × 8 repetisi | Motor encoding |
| 20–40 | **Materi baru** — 1 unit, 1 struktur tata bahasa | Input terstruktur |
| 40–50 | **Menyimak** — audio unit, 3× (buta → dengan teks → shadowing) | Persepsi bunyi |
| 50–60 | **Output** — 5 kalimat sendiri memakai struktur hari ini | Produksi aktif |

### Ritme Mingguan

| Hari | Fokus |
|---|---|
| Senin–Kamis | Unit baru (template 60 menit di atas) |
| Jumat | **Tidak ada materi baru.** Review + kuis unit minggu ini |
| Sabtu | Immersion bebas — drama/podcast/berita, tanpa target |
| Minggu | Libur total, **atau** simulasi ujian jika < 8 minggu menuju tes |

> Jumat tanpa materi baru bukan kemalasan — itu **konsolidasi**. Pelajar yang menambah materi 7 hari seminggu justru lupa lebih cepat.
